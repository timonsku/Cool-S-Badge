Lua scripts draw LED animations on the badge. Define frame(t) and set LEDs with led.set(i, hsv(i / led.count + t)); the badge shows each frame. See the script reference and the examples. A script that fails shows every other LED red.

      Color

      Touch an LED, or drag across several, to paint them. Off switches an LED off. Alt-click an LED to pick up its color.
